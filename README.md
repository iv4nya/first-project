# Проект помощи в создании первого репозитория на GitHub (Windows)


## Установка Git Bash на компьютер

1. Перейдите на [официальный сайт](https://git-scm.com/install/windows) для установки Git Bash
2. Скачайте и установите Git Bash


## Создание директории проекта

1. Откройте программу Git Bash
2. С помощью команды ```cd``` перемещайтесь по директориям устройства 
3. Создайте директорию в удобном для вас месте с помощью команды ```mkdir``` "название директории"

## Инициализирование репозитория

1. Находясь в папке проекта используем команду ```git init```
2. Пропишите команду ```git status```. Если все сделали правильно, появится такое сообщение:

- название текущей ветки: On branch master или On branch main;
- сообщение о том, что в репозитории ещё нет коммитов: No commits yet;
- сообщение, которое говорит: «чтобы что-нибудь закоммитить (то есть зафиксировать), нужно сначала это создать» — nothing to commit (create/copy files and use "git add" to track).

## Добавляем файлы в репозиторий

1. В папке проекта с помощью команды ```touch``` создайте текстовый файл в формате txt, например, ```touch "названиефайла.txt"```
2. Добавьте файл с помощью команды ```git add названиефайла.txt```

## Выполняем первый коммит

 С помощью команды ```git commit -m "комментарий коммита"``` выполняем свой первый коммит

## Просмотр истории коммитов

Для просмотра истории коммитов выполните команду ```git log```

## Регистрация на GitHub

Зарегестрируйтесь на [официальном](https://github.com/) ресурсе GitHub


## Создание удаленного репозитория

1. Зайдите в свой профиль по ссылке https://github.com/username, где username — имя, которое вы указали при регистрации.
2. Создайте репозиторий. Для этого перейдите на вкладку Repositories (англ. «репозитории»), а затем нажмите на зелёную кнопку New (англ. «новый») справа.
3. Открылось окно создания нового репозитория. Назовите его first-project. Название удалённого репозитория необязательно должно совпадать с именем папки проекта у вас на компьютере. Но чтобы не путаться, будем называть их одинаково.

- Другие поля вам пока не понадобятся. Смело нажимайте на зелёную кнопку Create repository (англ. «создать репозиторий») внизу.

## Генерация SSH ключа

1. Для генерации ключа используйте команду ```$ ssh-keygen -t ed25519 -C "электронная почта, к которой привязан ваш аккаунт на GitHub"```
2. Нажмите Enter 2 раза
3. Введите команду ```ls -a ~/.ssh ``` для проверки создания ssh ключа

## Связывание SSH ключа с GitHub

1. Вводим команду ```cat ~/.ssh/id_rsa.pub```
2. Копируем ключ
3. Переходим на GitHub
4. Добавляем ключ SSH
5. Введите команду ```$ ssh -T git@github.com``` 
6. Введите yes

## Связывание локального и удаленного репозитория

1. Копируем URL репозитория
2. Вводим команду ```git remote add origin git@github.com:%ИМЯ_АККАУНТА%/first-project.git```

- Убедиться в том, что репозитории связались можно с помощью команды ```git remote -v```

## Заключение

Репозиторий готов к работе, можно смело комитить и пушить :)
